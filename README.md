# 分块曲面的持久拓扑筛查与学习算子

`data/record.json` 是 分块曲面的持久拓扑筛查与学习算子 使用的本地合成交换样本。数组按 JSON 的下标顺序排列。本文的坐标、单位和枚举约定与该记录配套。记录中如果有 `scale` 或 `limits`，对应同一输入协议的部署规格。

规则用格点构成的方形胞腔复形，坐标按行、列。分区 box 是半开的顶点索引范围，边和面只有全部顶点在域内才有效。permanent_face_holes 是永久去掉的方格面左上顶点，保留它四条边和四个顶点。工艺允许循环是由这些开孔边界生成的同调子空间，比较使用满过滤范围中的类，不能按出生点是否靠近开孔判断。系数域 F₂。同分时按维度升序、同维按行列后接方向顺序（横、竖），使面在边后。持久度目标用给定权重乘持久度与目标差的平方，训练以查询结果中的完整配对身份选择目标，包含出生单元和消失单元。target_pairs 仅是工艺员选择目标前的消失格点、目标及权重提案，有多个配对时须给工艺员选择。

## 读取样本

使用 Python 3.11 或 3.12，并在虚拟环境安装锁定依赖。读取入口返回原始记录。作为命令运行时，它会列出各顶层输入项目以及 NumPy 版本。

```sh
python -m pip install -r requirements.txt
python -m persistence_loss_input
python -m unittest discover -s tests -v
```

测试读取交换样本，核对其中的张量尺寸、标识与数据约定。
