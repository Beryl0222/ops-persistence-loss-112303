# 分块曲面的持久拓扑筛查与学习算子

`data/record.json` 是本项目使用的本地合成交换样本。数组按 JSON 的下标顺序排列。
坐标、单位和枚举约定与该记录配套。记录中如果有 `scale` 或 `limits`，对应同一输入
协议的部署规格（如 1600×1600 部署面、64 行条带、约 48 MiB 划痕内存预算）。

规则用格点构成的方形胞腔复形，坐标按行、列。分区 box 是半开的顶点索引范围，
边和面只有全部顶点在域内才有效。`permanent_face_holes` 是永久去掉的方格面左上
顶点，保留它四条边和四个顶点。工艺允许循环是由这些开孔边界生成的同调子空间，
比较使用满过滤范围中的类，不能按出生点是否靠近开孔判断。系数域 F₂。同分时按
维度升序、同维按行列后接方向顺序（横、竖），使面在边后。持久度目标用给定权重
乘持久度与目标差的平方，训练以查询结果中的完整配对身份选择目标，包含出生单元
和消失单元。`target_pairs` 仅是工艺员选择目标前的消失格点、目标及权重提案，
有多个配对时须给工艺员选择。

## 读取样本

使用 Python 3.11 或 3.12，并在虚拟环境安装锁定依赖。

```sh
python -m pip install -r requirements.txt
python -m persistence_loss_input
python -m unittest discover -s tests -v
python -m topocoat.demo          # 端到端演示：复核、放行、台账替代、训练、条带、孔几何
```

## 包结构

| 模块 | 职责 |
| --- | --- |
| `topocoat.cells` | 单元身份（顶点/边/面键）、固定同分过滤顺序、半开 box 判定 |
| `topocoat.observation` | 分片合并与声明等价校验、缺片 vs 永久开孔区分、观测前沿、裁取/halo |
| `topocoat.engine` | F₂ 分维块持久同调：0D/1D 出生-合并/闭合、代表环、工作预算、可证明性 |
| `topocoat.openings` | 增广复形上的同调等价判定（允许开孔子空间），不靠出生点就近猜测 |
| `topocoat.review` | 工艺分区复查、阈值/分数区间查询、跨区代表路径、台账与旧未定替代 |
| `topocoat.training` | 可微持久度损失、规范格点梯度（重叠去重）、三类可解释跳过 |
| `topocoat.service` | 全工件/裁取/条带门面、换图兼容性检查 |

## 关键语义

### 过滤与配对

* 格点分数定义子水平过滤；边过滤值取两端点最大值，面取四角最大值；
* 同分固定顺序 `(过滤值, 维度, 行, 列, 方向)`，保证可复现的配对身份；
* 引擎按两个维块化简：边→顶点块识别连通分量合并与环出生，面→环边块识别孔洞
  闭合；每条 1 维条带代表边链（F₂ 闭合环），可直接交给工位定位。

### 缺片与可证明性

* 缺片格点不生成任何单元，只标记与其相邻的已建单元为**观测前沿**；永久开孔
  只去掉面、保留边和顶点，二者语义不混淆；
* 有限配对只有在配对两端及代表链全部不触前沿时才 `certified`；
* 无限条只有在窗口封口（无缺片）且代表链内部时才可证明，未封口窗口绝不把
  临时边界报成孔洞；
* 工作预算耗尽时 `PHResult.complete=False`，只返回已完成的配对。

### 工位复查

* 每个**已全观测**分区按分数范围与持久度阈值查询；
* 与允许开孔同调等价的循环 `release`，不发缺陷单；其余达标循环 `ticket`；
* 全工件复查在同一复形上归类条，跨区循环附带真实代表路径及经过的分区；
* `ReviewLedger` 保证：旧 `pending` 只能被新的可证明结论替代，已交付的
  certified 结论不会被静默翻转。

### 训练损失

请求必须携带完整配对身份（出生单元键 + 消失单元键）与带符号的目标持久度差：

```python
outcome = service.training_loss([
    TrainingRequest.make(pair_identity, target_delta=+1.0, weight=0.5)
])
```

* 损失 `w * (persistence - target)²`，梯度只落在影响出生/消失的原始格点上，
  并按规范 `(行,列)` 聚合——多片重复声明的同一格点是一个变量；
* 三类跳过均带原因：`undetermined`（缺片未定区域）、`identity_mismatch`
  （配对跳换/身份不存在）、`tie_risk`（同分变化可能跳换，严格模式跳过，
  宽松模式给次梯度并告警）。

### 条带化与换图

* `stripe_review` 用 halo 窗口分条计算：正持久孔洞的配对身份与全量化简逐对
  相同，无限条只在封口的末窗认证；零持久条在局部窗口允许出生身份不同；
* `TopoService.check_compatible` 校验尺寸、永久开孔几何、已观测格点分数与
  计分身份；换一张兼容图后仍可查询同一跨块孔洞、放行与训练信号；
* 改变人工孔几何（同分数）会真实改变无限 1 维条数量，可直接对比。
